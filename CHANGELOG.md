# Changelog

## v2.0.0-production - 2026-08-12

Module 2 Production v1.0 stable release.

### Production
- Production Orders with planned, released, in-progress, production-completed, completed, and cancelled states.
- Bill of Materials setup and version workflow.
- Product routing and production operation setup.
- Product cost calculation foundation.
- Worker reporting and production operation progress tracking.
- Production finalization workflow.

### Warehouse
- Material readiness checks for production orders.
- PMT material transfer workflow.
- PMC material consumption workflow.
- FGR finished goods receipt workflow.
- Batch/lot traceability.
- FEFO/FIFO allocation support.
- WIP warehouse integration.
- Finished goods warehouse integration.

### WMS
- Stock Inquiry.
- Material Stock Card.
- Low Stock reporting.
- WMS Dashboard.
- Finished Goods View.

### Documents
- PMT printable document.
- PMC printable document.
- FGR printable document.
- Audit log improvements for business-readable production and warehouse activity.

### UX
- Quantity formatting for discrete and continuous units.
- Friendly status labels.
- Production order timeline.

- Improved Production Orders filtering.
- Improved navigation.
- Production worker dashboard.
